# 微服务电商系统

基于 Spring Cloud 的微服务架构电商项目。

---

## 项目概述

一个完整的电商平台后端系统，包含用户、商品、订单、库存、AI 助手等核心业务模块。采用微服务架构设计，重点实践了分布式事务、高并发优化、安全认证等关键技术。

---

## 技术栈

- Spring Boot / Spring Cloud
- Spring Security + JWT
- MySQL + JPA
- Apache Kafka
- Eureka 服务注册发现
- Spring Cloud Gateway

---

## 核心功能

- 用户注册、登录、JWT 认证
- 商品管理
- 订单创建、查询、取消
- 库存管理
- AI 智能问答助手
- API 网关统一路由和鉴权

---

## 项目亮点

**分布式事务**
跨服务（订单 + 库存）的数据一致性，采用事件驱动 + Saga 模式保证最终一致性。

**并发性能优化**
订单预览接口并行调用多个下游服务，使用异步编排技术显著降低响应时间。

**安全体系**
网关层 + 服务层双层认证，JWT 令牌全程验证，实现纵深防御。

**服务解耦**
基于 Kafka 的事件驱动架构，服务间异步通信，降低耦合度。
